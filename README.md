## 🚀 Featured Project

### OVOMS — Multi-tenant logistics & route optimization platform

A logistics platform designed and developed end-to-end with a strong focus on scalability, tenant isolation and real-time operations.

- Backend built with **.NET 8, Clean Architecture and CQRS**.
- **RabbitMQ** for asynchronous processing and **Redis** for high-frequency real-time data.
- Live driver tracking using **Server-Sent Events and SignalR**.
- **Angular 20** frontend using standalone components, Signals and zoneless change detection.
- Role-based authorization with **JWT + tenant scoping**.
- Mobile driver application built with **Capacitor**, including background geolocation and offline-first delivery workflows.

**Stack:** `.NET 8` · `Angular 20` · `PostgreSQL` · `Redis` · `RabbitMQ` · `Mapbox` · `Capacitor` · `Docker` · `Nginx`
